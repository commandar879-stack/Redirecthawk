# RedirectHawk

RedirectHawk is a Python-based redirect validation and auditing utility designed for authorized security testing and research.

## Features

* Parameter discovery
* Redirect response analysis
* DOM redirect detection
* Colored terminal output
* Verbose scan mode

## Requirements

* Python 3.10+
* requests
* colorama
* beautifulsoup4

## Installation

pip install -r requirements.txt

## Usage

python redirecthawk.py -l targets.txt

## Disclaimer

Use only on systems you own or have explicit authorization to test.
